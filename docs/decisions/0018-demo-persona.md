# 0018 — Demo persona for hero video: accessibility user (motor impairment)

- Date: 2026-05-12
- Status: Accepted

## Context

The 90-second hero demo (build plan §1, dev plan §26) is the single most-distributed artifact for V1 launch. Persona choice determines emotional payload. Three options consistent with ADR 0002 (accessibility-first wedge): motor-impaired user, RSI-affected creator, atypical-speech user.

Motor-impaired persona is most universally legible — viewers instantly understand "hands-busy" as a real constraint, not stylistic. The IVC choice (a partner / mentor's voice) lands harder when the user genuinely cannot use a keyboard.

## Decision

Hero demo persona = **person with motor impairment** (specifically: RSI or post-injury reduced motor function — chosen to keep the visual approachable for first-time viewers; severe motor-impairment personas reserved for V2/V3 demo refreshes).

## Consequences

- Demo casting: prefer a real user from the beta cohort, not an actor.
- Script (§26.2) keeps the user's hands visible-but-still throughout; no keyboard typing scenes.
- The IVC voice should be a real person significant to the demo persona (a partner's or mentor's), with permission filmed if possible.

## Recovery

If we cannot recruit a real persona match by Week 5, an honest demo with a non-impaired actor framed as "imagine your hands aren't free" is the fallback. Clearly labeled as such in any release notes.
